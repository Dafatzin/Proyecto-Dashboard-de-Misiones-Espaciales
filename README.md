# Proyecto-Dashboard-de-Misiones-Espaciales
En este repositorio se realizará como proyecto final de Dev.f un Dashboard de Misiones Espaciales realizado por Atzin S. 
El dashboard va a incluir 4 categorías las cuales son: 
- Navegación: Posición y destino de la nave
- Núcleo de Energía: Combustible disponible y Potencia del reactor
- Estaus de la Nave: Integridad estructural y Daños localizados
- Soporte Vital: Oxígeno y presión y Estado de la tripulación
